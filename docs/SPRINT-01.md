# Sprint 01 — Base del producto

## Objetivo
Preparar la base de interfaz y dominio del MVP sin introducir persistencia ni datos personales.

## Criterios de aceptación
- [ ] `npm install` finaliza correctamente.
- [ ] `npm run dev` sirve el dashboard en localhost:3000.
- [ ] `npm run typecheck` no devuelve errores.
- [ ] `npm run lint` no devuelve errores.
- [ ] `npm run build` finaliza correctamente.
- [ ] Los datos del dashboard están identificados como ficticios.

## Seguridad
No añadir claves al repositorio. No conectar datos reales hasta disponer de autenticación, esquema multiempresa y políticas RLS probadas.
